      Install

      Bring another machine in. The steps, as stops on a line: a token to join with, the network boot that installs several machines at once, and a new recovery key for a node that keeps its state encrypted. Each asks first, and what it shows once is shown once.

      To write the answers file for a stick, use the installer page on the website: it makes kith-install.yaml, and the token below is its join: block.

      01 A join token

      Lets one machine in, for an hour. A control node votes and may do everything; a worker only runs what it is given.

      An address of one of this cluster's nodes, as the new machine sees it.

      02 Netboot

      This node answers machines that start from the network, hands each the installer once, and erases the disk it is told to. For an hour at most.

        kith-netboot.efi, made by os/build.sh.
        The network cards' addresses of the machines to install, with commas. No other machine is answered.
        A disk's name (nvme0n1), or only: the one disk, and none if there are two.
        The machines keep their state encrypted.

        03 A new recovery key

        For a node that keeps its state encrypted. The one it had stops working at once. The new one is shown once, and kept nowhere.
