    The guide

    What kith does and how to run it, one page for each part. Each is a markdown file in the repository; these are the same words.

    1. kith OS: kithd as the machine's first process

      On a kith OS machine there is the kernel and kithd, nothing else: no systemd, no shell.

    2. A cluster

      A node that holds the CA and listens on every address (--listen 0.0.0.0:7443, or a restart with no --listen) must say where others reach it, --advertise 192.168.1.10:7443, or kithd refuses to start....

    3. What kithd does today

      kithd keeps the store and runs what the resources say: containers, host processes, Jobs and CronJobs. kith talks to it over a unix socket only you can open. A second kithd on one state directory is refused.
